# 부찌대학 오늘근무 — 데모

직원이 매장 단말에서 자기 이름을 눌러 출근·퇴근을 찍으면, 사장은 달력에서 확인하고 급여 계산과 명세서까지 한 화면에서 끝내는 출근부입니다.
소문난의정부부대찌개 고대본점(부찌대학)에서 실제로 쓰는 도구를, **가상 직원 · 가상 기록**으로 바꾼 데모판입니다.

## 써 보는 법

1. `📱 단말 모드` → 이름의 **출근/퇴근** → 직원 PIN **0000**
2. 단말 화면 아래 `관리자` → 관리자 PIN **1234** → 달력, 월급 정산
3. 월급 정산의 `명세서` → 복사

- 직원 이름·시급·기록은 모두 가상입니다. 실제 매장 기록과 연결돼 있지 않습니다.
- 눌러 본 내용은 내 브라우저에만 저장됩니다. 맨 위 `데모 데이터 다시 채우기`를 누르면 처음 상태로 돌아갑니다.
- 파일은 `index.html` 하나입니다. 설치할 것이 없습니다.
